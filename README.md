# 🏡 Chácara Bia Festas

## 📌 Sobre o projeto

Este projeto foi desenvolvido para criar uma página web simples e intuitiva para a **Chácara Bia Festas**, destinada à locação do espaço para realização de eventos.

A escolha desse tema surgiu por ser um ramo de atuação dos meus pais, tornando o projeto uma oportunidade de aplicar os conhecimentos de programação em uma situação real.

A página apresenta informações sobre o espaço, fotos, vídeo, valores, condições de reserva e contato direto pelo WhatsApp.

## ▶️ Como executar

Na pasta do projeto, execute:

```bash
python -m streamlit run app.py
```
